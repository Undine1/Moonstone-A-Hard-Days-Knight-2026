# Moonstone 2026 v1.5

### Major updates

- Simplified the launchers and cleaned up the public build to reduce antivirus false positives.
- Removed developer tools and debug data from the public build. Normal error logging and startup diagnostics remain.

### Bug fixes

- Fixed the extra movement delay after hitting Troggs.
- Fixed the knight's death animation restarting when struck again while dying.
- Fixed Mudmen briefly appearing at the screen edge before emerging.
- Fixed quick button presses sometimes failing to roll the tavern dice. Gambling odds are unchanged.
- Fixed the knight disappearing and combat freezing during a spear Trogg's finishing attack.
- Fixed a garbled map flashing after receiving a Moonstone from the Guardian.
